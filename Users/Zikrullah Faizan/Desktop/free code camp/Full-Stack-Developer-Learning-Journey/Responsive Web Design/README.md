# Responsive Web Design Projects

This folder contains a collection of projects completed as part of the freeCodeCamp Responsive Web Design certification. Each project demonstrates core web development skills, including HTML, CSS, and JavaScript, with a focus on building responsive and accessible web pages.

## Projects Overview

- **Survey Form**: A simple and accessible survey form built with semantic HTML and styled for responsiveness.
- **Playing Cards**: An interactive project showcasing the use of CSS and JavaScript to display and manipulate playing cards.
- **Book Inventory App**: A basic inventory application for managing books, demonstrating CRUD operations and dynamic UI updates.
- **Product Landing Page**: A marketing landing page for a product, featuring responsive layouts, navigation, and engaging design elements.

Each project is organized in its own folder with all necessary files and assets. Explore the folders to see the code and try out the live demos.
