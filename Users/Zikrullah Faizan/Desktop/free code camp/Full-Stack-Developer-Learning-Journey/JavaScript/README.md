# JavaScript Projects

This directory contains a collection of JavaScript projects, each in its own folder with a dedicated README and source code. Each project demonstrates different concepts and skills in JavaScript, HTML, and CSS.

## Projects

### 1. Markdown to HTML Converter
- Convert Markdown syntax to HTML with live preview.
- Features: Headings, bold, italic, links, images, blockquotes, and more.

### 2. Drum Machine
- Play drum sounds using keyboard or mouse.
- Features: 9 drum pads, visual feedback, sound display.

### 3. Voting System
- Simple poll system using Map and Set.
- Features: Add options, prevent duplicate votes, display results.

### 4. Bank Account Management Program
- Manage a bank account with deposits, withdrawals, and transaction history.
- Features: Balance checking, transaction listing, validation.

### 5. Weather App
- Fetch and display weather data for major cities using a public API.
- Features: City selection, weather icon, temperature, humidity, wind, error handling.

## How to Use
1. Open any project folder.
2. Read the README for instructions.
3. Open the `index.html` file (if present) in your browser to run the app.
4. Explore the JavaScript code for logic and implementation details.
