# Drum Machine

A simple Drum Machine app built with HTML, CSS, and JavaScript. Click the pads or use your keyboard (Q, W, E, A, S, D, Z, X, C) to play drum sounds. The display shows the name of the sound played.

## Features
- 9 drum pads, each mapped to a unique sound and keyboard key
- Visual feedback when a pad is triggered
- Responsive and modern UI

## Sounds
| Key | Sound Name    |
|-----|--------------|
| Q   | Heater 1     |
| W   | Heater 2     |
| E   | Heater 3     |
| A   | Heater 4     |
| S   | Clap         |
| D   | Open-HH      |
| Z   | Kick-n'-Hat  |
| X   | Kick         |
| C   | Closed-HH    |

## Usage
1. Open `index.html` in your browser.
2. Click a pad or press a key to play a sound.
